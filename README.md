MUSH PORTFOLIO — VERCEL READY

This is a standalone static website for Vercel.

Files
- index.html: the complete portfolio. Images and the research report are embedded in this file.
- vercel.json: small static deployment configuration.
- README.md: these instructions.

Deploy/update
1. Extract this ZIP.
2. Upload or replace index.html and vercel.json in the ROOT of your existing GitHub repository.
3. Commit and push to your existing main branch.
4. Vercel will create a new deployment for the existing project. Your current domain remains attached to that project.

Vercel settings
- Framework preset: Other
- Root directory: ./
- Build command: leave empty
- Output directory: leave empty / default
