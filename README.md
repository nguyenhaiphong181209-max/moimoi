MUSH PORTFOLIO — VERCEL DEPLOY

This is a standalone static website. The page, photos, and research report are embedded in index.html.

To publish or update your existing Vercel site:
1. Replace the existing index.html in the ROOT of your GitHub repository with this index.html.
2. Keep the same repository, production branch, and Vercel project.
3. Commit and push the change. Vercel will create a new deployment automatically.

Recommended Vercel settings for this static site:
- Framework Preset: Other
- Root Directory: ./
- Build Command: leave empty
- Output Directory: ./

Do not rename index.html.
